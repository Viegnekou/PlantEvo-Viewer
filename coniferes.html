Les conifères

← Retour au menu

Le pollen transporte les cellules reproductrices mâles sans dépendre d'une pellicule d'eau. La graine protège l'embryon et nourrit son premier développement.

Appareil végétatif

Résister aux saisons

Les aiguilles réduisent les pertes d'eau et les tissus ligneux soutiennent les grands arbres. Les cônes portent les structures reproductrices. Les conifères sont des gymnospermes : leurs graines ne sont pas enfermées dans un fruit.

Le défi relevé

Reproduire sans eau libre

Le vent transporte le pollen jusqu'aux ovules. Après fécondation, une graine nue protège l'embryon en développement.

pollen → ovule → graine

Reproduction: Le cône mâle libère le pollen. Le cône femelle porte les ovules ; la graine se développe ensuite sur ses écailles, sans être enfermée dans un fruit.

Cône mâle → Pollen porté par le vent → Ovule fécondé → Graine nue
